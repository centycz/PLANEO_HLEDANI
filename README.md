# PLANEO_HLEDANI

Repozitář obsahuje dva nezávislé projekty:

## `nakupy/` — privátní nákupní aplikace

Webová aplikace pro nasazení na VPS (`nakupy.dalcortile.cz`): nákupní seznam pro
zadavatele a nákupčího, slevy z letáku, řazení podle úseků obchodu, oblíbené
položky, import katalogu z PDF a doporučení podle historie nákupů.

→ [dokumentace](nakupy/README.md) · [návod na nasazení](nakupy/deploy/PRVNI_NASAZENI.md)

## `scraper.py` — vyhledávání produktů

Původní skript pro dohledání parametrů produktu podle SAP čísla na webech
FastCR a Planeo.
